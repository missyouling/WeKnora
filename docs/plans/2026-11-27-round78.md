# 第 78 轮：维保记录重构 + 结算明细子表 + 随单附件袋 + 行驶证年检联动

## 目标

1. 维保记录卡片收敛为 `一般维修 | 二级维护 | 历史记录`，设置抽屉对齐能耗横向平级风格
2. 一般维修（维修结算清单）23 字段 + `line_items` 三子表 + 三道金额钩稽
3. 二级维护（竣工出厂合格证 + 质量保证卡）22 字段 + 双联票提取规则
4. 随单「非解析附件袋」（BYTEA 直存 + 无后缀预览 + 零解析）
5. 行驶证 `年检日期` 字段 + 证照状态 4 态联动
6. 铁律兜底（无序号列、无 `—`、唯一绿按钮）

## 关键决策

### 分类收敛：合格证并入二级维护
二级维护竣工出厂合格证与质量保证卡本就是同一份单据的两联，拆成两个分类会让用户
在两处各填一半。收敛后旧「合格证」分类**停用而非删除**（删了 KPI 卡片消失但记录
还在，用户找不到入口）；存量记录按字段别名映射迁到「二级维护」，**旧键全部保留**。

### 金额钩稽：三子表 + 浮点容差
金额一律按「元」的 number 处理（不换成分）。比较统一走 `AMOUNT_EPS = 0.01`，
避免 `0.1 + 0.2` 之类尾差误报。钩稽只在**明细非空**时校验——手工录入、
没有明细的老记录不该被红字追着改。

三道验算：
1. `Σ labor_fee == 工时费`
2. `Σ part_items.amount == 材料费`（且单行 `qty × unit_price == amount`）
3. `工时费 + 材料费 + 管理费 + 其它费 == 实际应收`

### 附件袋：只存不解 + 无后缀路由
- 纯 BYTEA 直存 PostgreSQL，上传链路**不引用任何 Extract\*/LLM**（源码层测试锁定）
- 预览走 `/fleet/attachments/view?id=...`：带 `.png`/`.pdf` 后缀的路径会被生产
  VPS 边缘 Nginx 的静态正则拦掉（第 61 轮离职证明 404 的同一个坑）
- 列表接口用 `Select` 显式排除 `content` 列，BYTEA 永不出现在 JSON 里

### 年检日期：月末归一 + 优先判据
「检验有效期至 2027年9月」表示整个 9 月都有效，取月末（9-30）而非月初——
取月初会让整月提前 30 天变「即将到期」。`年检日期` 放在 `CERT_STATUS_FIELDS`
链首：强制报废日期通常是 10 年后，用它算状态永远是「有效」，年检过期才是真实风险。
成功态文案为「有效」（年检是年度检验结论，说「生效中」不符合证照语义）。

## 踩过的坑

1. **附件表建表时机**：只在 Upload 里 `ensure` 建表，用户先打开抽屉（List）就撞
   `relation "fleet_record_attachments" does not exist` → 500。改为启动期 + List
   双向 ensure，`Count` 用 `HasTable` 前置判断。
2. **`partCount` 语义**：票面摘要的「4 件」指 4 **种**零件（行数），不是 qty 之和
   （同一螺丝买 4 个仍算 1 件）。
3. **e2e 连点失效**：在同一个 `evaluate` 里连点 N 次「添加」，只有第一次拿到按钮
   （后续点击时 Vue 还没重渲染），实测只加了 1 行。必须逐次点击 + 等待。
4. **t-date-picker 不吃 dispatchEvent**：`dispatchEvent('input')` 只改了 DOM 的
   `input.value`，组件 model 没变，证照状态因此不动。必须用真实键盘 `fill` + `Enter`。
5. **胶囊激活类名**是 `fc-group-tab active`（不是 `is-active`）。
6. **维保规则面板的 certTypeOptions** 走 fleet 分组结构（带 `group`/`children`），
   方块标签渲染为空。维保需平铺成 `{label, value}` 数组。
7. **`fleetTenantID` 返回 `uint64`**，附件结构体字段是 `int64`，必须显式转换。
